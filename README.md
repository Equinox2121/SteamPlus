## Requirements
* Install [Node.JS](https://nodejs.org/en).
## Local Installation

Open a terminal in the `backend` and `frontend` folder and run:

    bash npm install

Run `package.json` dev scripts, backend first:

    nodemon server.js 

and frontend:

    vite

both can be located in the `package.json` scripts.
