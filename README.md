## Installation Guide for Development

### Requirements
* Install [Node.JS](https://nodejs.org/en).
### Installation

Open a terminal in the `backend` and `frontend/app` folder and run:

    bash npm install

Run `package.json` dev scripts, backend first:

    nodemon server.js 

and frontend:

    vite

both can be located in the `package.json` scripts.
